04왜 요기요에 이 서비스가 필요한가

가격 경쟁에서 콘텐츠 경쟁으로

쿠폰·무료배달 같은 거대 자본 기반 마케팅으로는 3위 사업자가 맞서기에 한계 존재

→ 요기요만의 매력적인 콘텐츠로 유저가 쓸 이유 만들기

단발성 프로모션에서 일상 루틴으로

프로모션은 일회성 방문에 그치고, 배달 니즈가 없으면 앱을 열 이유가 없음

→ 사주에 날씨·기온·습도를 매일 결합해 "오늘 내 체질에 이 음식" 명분 제공

개인 콘텐츠에서 그룹 콘텐츠로

팀 점심·회식은 메뉴 정하기부터 어렵고, 사주에 관심 없는 사람은 개인 콘텐츠를 쓰지 않음

→ 팀원 기운을 합쳐 추천하는 그룹 미식 궁합 모드로 메뉴 결정 부담 해소

배달 인프라를 직접 보유한 요기요는 체질 진단 → 메뉴 추천 → 점포 매칭 → 즉시 주문·멤버십 연동까지 한 번에 잇는 완결형 퍼널 구축 가능

06핵심 기능

1. 듀얼 트랙 웰니스 진단

2030은 사주(오행), 4050+는 건강형(8체질)으로 선택하거나 결합합니다. 의료적 표현은 배제하고 면책을 고지합니다.

2. 실시간 AI 초개인화 추천

당일 기상 변수와 체질을 벡터 검색으로 매칭하고, 과거 주문 이력을 더해 맞춤 웰니스 문장을 생성합니다.

3. 그룹 오더

링크로 팀 오더를 열고, 비회원도 생년월일시만 입력해 참여합니다. 팀원 전체의 결핍 기운을 집계해 후보 3~5개로 투표합니다.

4. B2B 스폰서 매칭 광고

진단 결과와 맞는 매장에만 노출 우선순위를 주는 타겟팅 도구로, 광고 수익을 만듭니다.

5. 콘텐츠 리워드

추천으로 결제하면 체질 맞춤형 웰니스 케어 혜택이나 스탬프를 지급해 다음 날 재방문을 유도합니다.

6. SNS 공유와 자발적 확산

진단 결과를 카드뉴스로 바로 만들어 공유하게 해 신규 유입을 늘립니다.
